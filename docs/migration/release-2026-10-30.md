# McPort 0.5.0: Silicon Cells and Accounts 0.7

Its encrypted records are in the cell's PostgreSQL database. The website remains
on Vercel and the public API remains `https://api.mcport.teamofsilicons.com`.
Local daemons, provider callbacks and Accounts webhooks retain their addresses.

## Migration and operation

The old `mcport-accounts` writer was stopped and disabled before the final
snapshot. Its SQLite backup timer was also disabled. The original database,
master key, runtime settings and Caddy configuration remain in protected backups.
The final archive SHA-256 is
`f94cc921a5af2396b4ec5d1e7413ef28b342127e59061eb313ff0be56b9014b2`.

The importer authenticated every encrypted record, verified all ten table
digests, and committed 522 records, 523 allocated IDs, 513 replay links, two
account rows and six webhook receipts. The allocator and empty identity,
allowance and account-migration tables were preserved as well. The original
ciphertext, AAD and master key were retained. The target was verified empty
before import. No old/new application writers ran concurrently.

The maintenance command ran at 11:46 UTC and the public edge switched at
12:08 UTC on October 30, approximately 22 minutes. The final import completed
at 12:04:44 UTC. The Cells service passed its exact version/source health check
before public traffic moved. Caddy's bytes outside the API site retained SHA-256
`dabd0bf7e0cfc06bbb598c75a93620ef654041e4123075d647037ac3ecfafb42`.

The edge connects to the verified `api.cells.teamofsilicons.com` TLS origin with
the fixed cell Host. This avoids the wildcard CDN's 120-second deadline. Cells'
outer service middleware, service proxy, the fixed origin route and the McPort
edge use a bounded 630-second budget. Functions and unrelated origin routes keep
their existing limits. Service ingress accepts 20 MiB. No CDN signing credential
was copied to the McPort edge. See [the deployment runbook](../../deploy/cells/README.md).

Cells creates daily encrypted database snapshots. An additional production
snapshot, `90cafc6f-ea79-467e-ab32-c8f8852bcfac`, is Ready and expires November 29.
Its snapshot point is October 30 at 12:09:44 UTC. The 826,158-byte download was
verified by the Cells CLI and independently matched metadata SHA-256
`e7dcc903cec69ff730ad3684eb7688b7150c31daed592233eb95306743cc5dad`.
Its archive contains all eleven McPort tables, including the storage-key marker.
The recovery API reported a ready recovery window.

A recovery smoke test restored the McPort tables, sequences, constraints and
data into a new disposable local PostgreSQL database. Cells-managed event-capture
triggers were omitted for this standalone check. Seven pre-cutover fixture IDs
were retained, and McPort 0.5.0 started healthy with the original master key,
authenticating every encrypted record during startup. External integrations were
disabled; the test process and database were removed afterward. The production
database was not restored or replaced. App secrets remain in Cells Secrets with a
separate protected original backup; they are not in Git or images.

After new writes reach Cells, starting the old SQLite writer is not a rollback.
Use coordinated database recovery and preserve replay ledgers; the runbook
describes this boundary.
