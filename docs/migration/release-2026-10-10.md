These checks reused genuine Accounts CLI credentials in a production BFF test cookie. They do not claim a separate completed browser SSO redirect. The genuine SLT exchange is independently proven.

The result included structuredContent. This public provider requires no credential; the earlier authenticated-provider and local-daemon proofs remain separately documented local evidence. The disposable production connection was deleted after verification, and a fresh connection listing returned an empty array. The historical call evidence remains retained.

The actual Silicon UI registry supplies the components and foundation. App-owned aliases preserve numeric spacing and radius tokens. Decorative account initials are hidden from accessibility names. There are no active setup/update scripts fetching uiarc.dev; inherited MIT notices remain. ## Data isolation, recovery and cleanup

The Accounts service uses a fresh store and independent keys under `/var/lib/mcport-accounts`, private runtime configuration under `/etc/mcport-accounts`, and a separate service unit. Existing IAM Silicons, custody, credentials, workers, records and Honeycomb packages remain on the old service. The Accounts website initially shows Accounts-created data only. No legacy account was imported or re-enrolled.

The independent daily `mcport-accounts-backup.timer` is active. The initial matching database/key/configuration snapshot is encrypted in private S3 at `parallel-accounts-20261010/mcport/backups/20261010T142451Z.tar.gz` (SHA256 `7b59366cf61b7a02b424324166d488120da147920bf8788a0ab8994caa564d10`). See [deployment and restoration instructions](../../deploy/parallel/README.md). Rollback targets only the new service or website; never point the new binary at the legacy database or replace legacy keys.

Temporary local development, provider, daemon and website processes started for this task are stopped. Protected local fixtures, migration maps, release archives and evidence remain recoverable. Production units and their backup timers remain running. Private receipts and screenshots are in the operator workspace `.migration/live/mcport-accounts` and `.migration/live/genuine-cli`; credentials are excluded from Git.

No MCPort deployment or package-publication gate remains. Verification limitations are stated above; no broad provider-compatibility or legacy-resource adoption claim is made.
