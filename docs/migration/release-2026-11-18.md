## Production acceptance

- A standalone Chromium page on a separate origin used an Accounts-issued McPort bearer to read identity and list the directory. It created, read, updated and deleted a private entry. Anonymous access returned 401.
- The signed-in McPort web app resolved a Carbon’s public photo, created a temporary contact, changed its trust, and selected its saved name by fuzzy keyboard search. The Silicon Contacts API returned the same saved name and trust. The test contact was removed.
- The shared Silicon enabled, disabled and re-enabled McPort notifications through Ting. The registered types were `mcport.connectionShared` and `mcport.directoryEntryShared`. The original Contacts and Ting preferences were restored after verification.
- The production personal Silicon received an empty work-account membership view and got 403 when it tried to create a team connection.

## Isolated acceptance

- Real Silicon Accounts issued a McPort access token through an Interface consent and PKCE exchange. It authorized McPort operations, refreshed successfully and received 401 immediately after the Interface grant was revoked.
- A work admin created a connection through McPort using live membership from a local Silicon Organizations service. A work Silicon on that team called an MCP provider through the connection. The linked personal account and a nonmember could not use it. Removing the Silicon from the team cut off its existing token. Separate router checks exercised team-admin ownership and continued use after the connection’s creator left.
- Disposable shares verified that McPort queued a single Ting for a repeated grant and addressed it to the intended Silicon. Cross-account share delivery was exercised with test recipients. The production checks used the shared Silicon’s own enrollment.
- The 32 browser checks covered the independent frontend, genuine Interface authentication, the signed-in product, keyboard interactions, desktop and mobile accessibility, sessions and sign-out. The native end-to-end journey passed all 102 checks.
